# Pack WIP 1.20.1

Web del modpack WIP para los amigos del servidor: la lista de mods, cómo está
ajustado cada uno, las teclas, cómo entrar al servidor y los mods porteados o
arreglados para bajar.

Cada `.zip` de `descargas/` lleva el `.jar`, la licencia del autor original y un
`LEEME.txt` con lo que se cambió. Los ports son versiones no oficiales: los
problemas que tengan no son culpa de los autores originales.

Los mods cuya licencia no permite compartirlos aparecen en la página sin descarga.
